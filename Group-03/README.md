## Project Title
AttritionIQ – Employee Attrition Prediction & Retention Analytics

## Project Description
AttritionIQ is a machine learning-based application that predicts employee attrition risk and provides analytics to help organizations understand employee retention.

The project compares three machine learning algorithms:
- Random Forest
- Extra Trees
- Gradient Boosting

It also provides employee risk segmentation, model comparison, feature importance, SHAP explainability and a retention simulator.

## Objectives
- Predict employee attrition.
- Identify important factors influencing employee attrition.
- Compare machine learning models.
- Segment employees based on attrition risk.
- Support employee retention decisions.
