# Statlog German Credit dataset

H. Hofmann, Statlog (German Credit Data), UCI Machine Learning Repository, 1994.
DOI https://doi.org/10.24432/C5NC77
Source https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data

The original german.data file contains 1,000 rows, 20 input attributes and one target column. Original target values are 1 for good and 2 for bad credit risk. TEXL encodes bad risk as 1.
